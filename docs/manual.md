## 1. 설치와 첫 실행

**요구 사항**: macOS 14(Sonoma) 이상, Apple Silicon(M1 이후) 맥

1. [Releases](https://github.com/SeaViewer91/GeoStat/releases)에서 `GeoStat_<버전>_aarch64.dmg`를 받음
2. dmg를 열고 `GeoStat.app`을 응용 프로그램 폴더로 끌어 옮김
3. 처음 열면 "확인되지 않은 개발자" 경고가 뜸. Apple 공증을 받지 않은 앱이기 때문임. 아래 중 하나로 한 번만 허용함
   - **시스템 설정 → 개인정보 보호 및 보안** 맨 아래 **"그래도 열기"**
   - 터미널: `xattr -dr com.apple.quarantine /Applications/GeoStat.app`

첫 실행은 분석 엔진을 준비하느라 10~20초 걸릴 수 있음. 하단 상태 표시줄 오른쪽에 `엔진 0.9.0 · GDAL …`이 보이면 준비된 것임.

**업데이트**: 새 버전이 나오면 오른쪽 위에 알림이 뜸. **설치 후 다시 시작**을 누르면 받아서 설치하고 다시 켬.
**도움말 → 업데이트 확인…**으로 직접 확인할 수도 있음. 업데이트 파일은 서명을 확인한 뒤에만 설치함.

**언어**: **도움말 → English**로 영어 화면으로 바꿀 수 있음. 분석 엔진이 만드는 오류 메시지와 보고서는 한국어로만 나옴.

## 2. 화면 구성

| 영역 | 내용 |
|---|---|
| 위 도구 모음 | 파일·공간 분석·도움말 메뉴, 차트 패널, 선택 도구(이동·사각형·올가미), 선택 반전·해제, 배경지도 |
| 왼쪽 패널 | 레이어 목록, 래스터 목록·표시 설정, 주제도 설정과 범례, 공간가중치 |
| 가운데 | 지도. 아래는 속성 테이블 (경계선을 끌어 높이 조절, ⌘T로 숨기기) |
| 오른쪽 패널 | 차트와 분석 보고서 (⌘J) |
| 아래 상태 표시줄 | 활성 레이어의 피처·선택 수, 실행 중인 작업의 진행률·취소 버튼, 엔진 버전 |

레이어 목록에서 누른 레이어가 **활성 레이어**임. 주제도·속성 테이블·분석 메뉴는 활성 레이어에 적용됨.
레이어 목록의 앞쪽이 지도에서 위에 그려지고, 래스터는 항상 벡터 아래에 그려짐.

## 3. 데이터 열기

**파일 → 데이터 열기…**(⌘O)로 엶. 지원 형식은 아래와 같음.

| 종류 | 형식 |
|---|---|
| 벡터 | Shapefile, GeoPackage(레이어가 여럿이면 고르는 창이 뜸), GeoJSON, FlatGeobuf, KML, GML |
| 표 | CSV·TSV·TXT, 엑셀(xlsx·xls). X·Y 좌표 열과 좌표계를 골라 점으로 만듦 |
| 래스터 | GeoTIFF·COG, IMG, VRT, ASCII Grid, JPEG2000 |

- **한글 인코딩**: Shapefile의 DBF가 cp949(EUC-KR)인지 UTF-8인지 자동으로 판별함. `.cpg` 파일이 없어도 됨
- **좌표계가 없는 자료**: 지도에 올릴 수 없어 좌표계 지정 창이 뜸. EPSG:5186(중부원점), 5179(UTM-K), 5174(구 중부원점) 등 한국 좌표계 프리셋이 있음. 레이어의 **좌표계 지정** 버튼이나 왼쪽 정보 칸의 **지정…**으로 나중에 바꿀 수도 있음. 좌표 값은 바꾸지 않고 좌표계 정보만 붙임
- **표 파일**: 좌표 열 이름(X·Y, 경도·위도, lon·lat 등)과 좌표계를 추정해 채워 줌. 확인하고 **열기**를 누름
- 피처가 50만 개를 넘으면 지도 이동·선택이 느려질 수 있다고 알림

## 4. 주제도

왼쪽 **주제도**에서 변수와 방법을 고르고 **적용**을 누름.

| 방법 | 설명 |
|---|---|
| 분위수 | 개수가 같도록 나눔 |
| 등간격 | 값 범위를 같은 폭으로 나눔 |
| 자연 분류 (Jenks) | 계급 안의 차이가 작도록 나눔 (3,000개가 넘으면 표본으로 경계를 구함) |
| 표준편차 | 평균에서 ±1σ, ±2σ로 나눈 6계급 |
| 백분위 | 1·10·50·90·99% 경계 6계급 |
| 박스 지도 | 사분위수와 1.5 IQR 울타리. 이상치를 따로 보여 줌 |
| 0 기준 발산 | 음수는 파랑, 양수는 빨강. GWR 계수·잔차처럼 부호가 중요한 값용 |
| 고유값 | 범주별 색 (12개가 넘으면 나머지는 '기타') |
| LISA·Gi*·Local Geary 군집, 유의성 지도 | 국지 통계 결과 열용 |

- 범례 항목을 누르면 그 계급의 피처가 선택됨 (⌘를 누르고 누르면 추가)
- GWR 계수 열은 **유의하지 않은 지역 가리기**를 켜면 다중검정 보정 후 유의하지 않은 곳을 회색으로 칠함
- 배경지도(밝은 지도·기본 지도)는 OpenFreeMap을 쓰며 인터넷 연결이 필요함

## 5. 속성 테이블과 선택

- 열 머리글을 누르면 정렬함. 한 번 더 누르면 반대 순서
- 행을 누르면 지도에서 선택됨. 지도·테이블·범례·차트의 선택은 모두 연동됨
- **선택 항목만**: 선택한 행만 보여 줌
- 선택 도구: **이동**(클릭 선택), **사각형**(B, 또는 Shift+끌기), **올가미**(L, 피처 중심점이 안에 들면 선택). ⌘를 누르면 기존 선택에 추가함
- **조건 선택…**: 속성 조건으로 선택함. pandas 조건식 문법이며 한글 열 이름은 백틱으로 감쌈
  - 예: `` `인구` > 5000 and `구분` == '도심' ``
- **계산 필드 추가…**: 식으로 새 변수를 만듦. 프로젝트를 다시 열면 같은 식으로 다시 계산함
  - 예: `` `인구` / `면적` * 1000 ``, `` log(`소득`) ``, `` (`인구` > 5000) * 1 ``
- **내보내기…**: GeoPackage·Shapefile·GeoJSON·FlatGeobuf·CSV로 저장함. 좌표계를 바꿔 저장할 수 있고, Shapefile은 인코딩(cp949·UTF-8)을 고를 수 있음

## 6. 공간가중치

**공간 분석 → 공간가중치 만들기…**에서 만듦. 만든 가중치는 왼쪽 **공간가중치** 칸에 쌓이고, 분석 창에서 골라 씀.

| 종류 | 설명 |
|---|---|
| Queen·Rook 인접 | 경계(Queen은 꼭짓점 포함)를 공유하면 이웃. 차수를 높이면 이웃의 이웃까지 포함 |
| 거리 기준 | 정한 거리 안의 피처가 이웃. 모든 피처가 이웃을 하나 이상 갖는 최소 거리를 제안함. 역거리 가중 가능 |
| KNN | 가까운 k개가 이웃 |
| 커널 | 거리에 따라 가중치가 줄어드는 커널 (삼각·균등·이차·사차·가우시안) |
| 파일 | GeoDa `.gal`·`.gwt` 불러오기·저장 |

- 경위도 자료는 거리 계산 때 UTM으로 바꿔 m 단위로 계산함
- 가중치를 만들면 연결성 히스토그램과 섬(이웃 없는 피처) 수를 보여 줌. **이웃 선택**은 선택한 피처의 이웃을 선택함

## 7. 탐색적 공간자료분석 (ESDA)

- **Moran's I · Moran 산점도**: 전역 공간 자기상관. 이변량 Moran도 가능. 순열 검정으로 유사 p값을 구함. 산점도에서 끌어 선택하면 지도와 연동됨
- **국지 통계 (LISA · Gi* · Local Geary)**: 피처별 군집·이상치. 결과는 통계량(LISA `_I`, Gi* `_Z`, Local Geary `_C`)·군집 코드(`_CL`)·p값(`_P`) 열로 저장되고 군집 지도가 바로 그려짐
  - FDR·Bonferroni 보정을 고를 수 있음. 난수 시드를 고정해 결과가 재현됨
  - LISA 군집: High-High(빨강), Low-Low(파랑), Low-High·High-Low(옅은 색)
- **Join Count**: 0/1 변수의 이웃 결합 수(BB·BW·WW)와 검정
- **차트**: 히스토그램·산점도·박스플롯·Moran 산점도. 차트에서 끌어 선택하면 지도·테이블에 반영됨

## 8. 회귀 분석

**공간 분석 → 회귀 분석…**. 종속변수 하나와 독립변수 여러 개를 고름. 계산은 별도 작업으로 돌아가며 상태 표시줄에서 진행률을 보고 취소할 수 있음.

| 모형 | 설명 |
|---|---|
| OLS | 최소제곱. 가중치를 고르면 잔차 Moran's I와 LM 검정(LM·Robust LM lag/error, SARMA)으로 공간 의존성을 진단하고 모형 선택을 안내함. White 강건 표준오차 선택 가능 |
| 공간시차 (ML·GM) | y = ρWy + Xβ + ε. 직접·간접(파급)·총 효과 표를 함께 보여 줌 |
| 공간오차 (ML·GM) | u = λWu + ε. GM은 이분산에 강건함 |
| GWR | 위치마다 계수가 다른 회귀. 커널·고정/적응 대역폭·AICc 등 기준으로 대역폭을 찾음 |
| MGWR | 변수마다 대역폭이 다른 GWR. 오래 걸리므로 관측치 5,000개 이하를 권함 |

- 결과는 오른쪽 보고서 카드에 나옴: 요약, 계수표(* p<0.05), 진단, 지역 계수 요약(GWR·MGWR)
- 예측값(`_PRED`)·잔차(`_RESID`) 열이 저장되고, GWR·MGWR은 지역 계수(`_B_`)·t값(`_T_`)·유의 여부(`_SIG_`)·지역 R² 열도 저장됨
- GWR 보고서의 지역 계수 표에서 행을 누르면 그 변수의 계수 지도로 바뀜
- 회귀를 두 번 이상 돌리면 **모형 비교** 표가 나옴: R², 로그우도, AICc, 잔차 Moran's I. 종속변수가 같은 모형 중 AICc가 가장 낮은 모형에 '최적'을 표시함
  - AICc는 σ²를 모수로 포함해 mgwr과 같은 식으로 계산함. MGWR은 원래 척도로 환산한 값임
- **보고서 저장…**으로 텍스트 보고서를 저장함

## 9. 군집 분석

**공간 분석 → 군집 분석…**. 변수를 고르고(보통 표준화), 방법과 군집 수를 정함.

| 방법 | 설명 |
|---|---|
| SKATER | 이웃 그래프의 최소 신장 트리를 잘라 연결된 지역으로 나눔. 빠름 |
| Max-p | 지역마다 최소 합계(예: 인구 5만)를 만족하면서 지역 수가 최대가 되게 나눔. 무거움 |
| AZP | 경계 피처를 옮겨 가며 지역 내 차이를 줄임 |
| Region K-Means | 연결 제약을 둔 K-평균. 느림 |
| Ward (공간 제약) | 이웃끼리만 병합하는 계층 군집. 빠름 |
| K-평균·계층적 군집 | 위치를 고려하지 않음. 공간 제약 결과와 비교용 |

- 결과: `<접두어>_GRP` 열(큰 군집부터 1번)과 군집 지도
- 보고서: 군집 간/전체 제곱합 비, 군집별 크기·변수 평균(전체 평균보다 높으면 빨강, 낮으면 파랑), 공간 조각 수. 행을 누르면 그 군집을 선택함
- 이웃이 여러 조각으로 나뉜 가중치(섬 포함)는 AZP·Max-p·Region K-Means에서 쓸 수 없음. KNN 가중치를 쓰면 됨

## 10. 래스터

- **표시**: 래스터를 열면 왼쪽 **래스터** 패널에서 밴드·색상표·값 범위(2–98%, 최소–최대, 직접 입력)·투명도를 바꿈. 밴드가 3개 이상이면 RGB 합성도 가능함
- **오버뷰 만들기**: 큰 영상(긴 변 4,096픽셀 초과)에 오버뷰가 없으면 축소해서 볼 때 느림. 버튼을 누르면 원본 옆에 `.ovr` 파일을 만듦 (원본은 바꾸지 않음)
- **존 통계** (공간 분석 → 존 통계): 폴리곤마다 래스터의 평균·최솟값·최댓값·표준편차·합계·중앙값·사분위·최빈값 등을 새 열로 붙임. 셀이 폴리곤에 걸친 면적 비율로 가중함
- **격자 만들기** (공간 분석 → 격자 만들기): 래스터나 레이어 범위를 덮는 정사각·육각 격자를 GeoPackage로 저장하고 엶. **만든 뒤 바로 존 통계 계산**을 켜면 래스터를 격자로 요약해 곧바로 LISA 등을 적용할 수 있음

## 11. 프로젝트와 내보내기

- **파일 → 프로젝트 저장**(⌘S): `.gstproj` 파일로 저장함. 데이터 자체는 담지 않고 원본 경로와 작업 과정(좌표계 지정, 계산 필드, 가중치, 분석, 주제도, 차트, 래스터 표시 설정)을 기록함
  - 원본 경로는 프로젝트 기준 상대 경로와 절대 경로를 함께 저장해, 폴더째 옮겨도 열림
  - 회귀·군집·존 통계 결과는 프로젝트 옆 `.gstcache` 폴더에 저장해 다시 열 때 재계산하지 않음. 캐시가 없으면 다시 계산함
- **파일 → 지도 이미지 저장 (PNG)…**: 지금 보이는 지도를 범례·출처와 함께 PNG로 저장함
- **파일 → 레이어 내보내기…**: 분석 결과 열을 포함해 다른 GIS 형식으로 저장함

## 12. 따라 해 보기 (샘플 데이터)

**도움말 → 샘플: …**을 고르면 샘플을 `문서/GeoStat/샘플 데이터` 폴더에 복사하고 엶.

### 조지아 교육 수준 — GWR

1. **샘플: 조지아 교육 수준 (GWR 예제)** 열기
2. **공간 분석 → 공간가중치 만들기…** → Queen → 만들기
3. **회귀 분석…** → 모형 OLS, 종속변수 `PctBach`, 독립변수 `PctRural`·`PctFB`·`PctBlack` → 실행. 잔차 Moran's I가 유의한지 봄
4. 같은 변수로 모형 GWR(가중치 칸을 켜 두면 잔차 Moran's I도 계산) → 실행. 대역폭 117(이웃 수)이 나옴 (mgwr 문서와 같음)
5. 보고서의 지역 계수 표에서 `PctRural` 행을 누르면 계수 지도로 바뀜. **모형 비교** 표에서 AICc를 비교함

### 노스캐롤라이나 영아 돌연사 — LISA

1. **샘플: 노스캐롤라이나 영아 돌연사 (ESDA 예제)** 열기
2. Queen 가중치를 만들고 **Moran's I · Moran 산점도…**에서 `SIDR79`를 봄
3. **국지 통계…** → LISA, 변수 `SIDR79` → 실행. High-High 군집이 어디인지 확인함

### 서울 가상 지형 — 래스터를 격자로

1. **샘플: 서울 가상 지형 (래스터)** 열기
2. **공간 분석 → 격자 만들기…** → 범위: 래스터, 정사각 500 m, **만든 뒤 바로 존 통계 계산** 켜기 → 만들기
3. 새 격자 레이어에 Queen 가중치를 만들고 `ZS_MEAN`으로 LISA를 돌림

## 14. 문제 해결

| 증상 | 해결 |
|---|---|
| "확인되지 않은 개발자"라서 열리지 않음 | 1장의 "그래도 열기" 절차를 따름 |
| "앱이 손상되었습니다" | 터미널에서 `xattr -dr com.apple.quarantine /Applications/GeoStat.app` |
| 한글 속성이 깨짐 | 파일이 cp949·UTF-8이 아닌 다른 인코딩일 수 있음. 원본을 UTF-8로 저장해 다시 열어 봄 |
| 지도에 안 보임 | 좌표계가 없거나 잘못됐을 수 있음. 정보 칸의 좌표계를 확인하고 **지정…**으로 바꿈 |
| "분석 엔진이 멈춤" 알림 | **엔진 다시 시작**을 누름. 열려 있던 데이터는 닫히므로 프로젝트를 저장해 두었다면 다시 엶. 계속되면 GitHub Issues에 알려 주면 됨 |
| MGWR·Max-p가 너무 오래 걸림 | 상태 표시줄의 **취소**로 멈춤. 관측치를 줄이거나 GWR·SKATER를 먼저 써 봄 |
| 큰 래스터가 느림 | 래스터 패널의 **오버뷰 만들기** |

문제를 찾으면 [GitHub Issues](https://github.com/SeaViewer91/GeoStat/issues)에 알려 주면 됨.
