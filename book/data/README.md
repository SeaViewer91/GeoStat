# 한빛시 예제 자료

책 전체에서 쓰는 가상 도시 **한빛시**의 자료임. 1강에서 처음 소개함.

| 파일 | 형태 | 내용 |
|---|---|---|
| `hanbit_dong.gpkg` | 면 | 행정동 150개. 동코드, 구, 동이름, 인구, 고령인구(65세 이상), 면적_km2 |
| `hanbit_events.gpkg` | 점 | 2025년 6~8월 폭염 관련 119 구급 출동 1,408건. 출동ID, 출동일, 월, 연령대 (연령대는 3강에서 참 모형에 맞게 다시 만듦. 위치·날짜는 그대로) |
| `hanbit_stations.gpkg` | 점 | 기상 관측소 48곳. 관측소ID, 기온_8월평균(℃) |
| `hanbit_roads.gpkg` | 선 | 주요 도로 4개. 도로명, 등급 |
| `hanbit_lst.tif` | 래스터 | 여름 한낮 지표온도(℃), 50 m 셀 640×480, 바다는 값 없음(-9999) |
| `hanbit_pop100.tif` | 래스터 | 100 m 격자 인구(1밴드)와 고령인구(2밴드), 320×240, 바다는 값 없음(-1). 행정동 인구를 동 안의 인구 분포에 따라 나눠 담은 값. 3강에서 추가 |
| `hanbit_boundary.gpkg` | 선 | 시 경계를 해안선(약 54 km)과 이웃 시와 맞닿은 행정 경계(약 45 km)로 나눈 선 2개. 구분 필드. 4강에서 추가 |
| `hanbit_dong_panel.gpkg` | 면 | 행정동 150개 × 2016~2025년의 긴 형태 패널 1,500행. 동코드, 구, 동이름, 연도, 인구, 고령인구, 출동건수(6~8월 폭염 관련 119 구급 출동), 폭염일수(도시 전체), 면적_km2. 경계는 모든 연도에 2025년 행정동 경계이고, 2025년 값은 `hanbit_dong.gpkg`와 `hanbit_events.gpkg`의 동별 건수와 같음. 33강에서 추가 |

- 좌표계는 모두 EPSG:5186(중부원점)임
- **모든 값은 가상임.** 실제 지명·통계와 관계없음. 실제 지형과 겹치지 않도록 서해 바다 위(동경 125.0~125.4°, 북위 36.5~36.8°)에 두었으므로, 배경지도를 켜면 도시가 바다 위에 뜸
- 모든 값은 알려진 규칙(참 모형)으로 만들었음. 규칙은 `make_hanbit.py`와 `make_hanbit_panel.py`에 그대로 있지만, 책을 끝까지 읽기 전에는 보지 않기를 권함. 분석 방법이 참 구조를 찾아내는지 스스로 확인해 보는 재미가 있기 때문임. 규칙은 부록 G에서 정리함

## 연습용 자료 (`practice/`)

본 분석에는 쓰지 않고, 흔한 문제를 일부러 재현해 둔 자료임.

| 파일 | 형태 | 내용 |
|---|---|---|
| `practice/hanbit_dong_sim.gpkg` | 면 | 공간 회귀 연습용 모의 자료. 행정동 150개에 `고령비율`, `온도편차`(8강과 같은 방법으로 계산)와, 규칙을 공개한 모의 변수 `Y_독립`, `Y_시차`(공간시차 과정, ρ = 0.5), `Y_오차`(공간오차 과정, λ = 0.5)를 담음. 28강에서 중심점 좌표 `X_km`, `Y_km`과 계수가 지역마다 다른 `Y_체제`(다솜구만 온도편차 계수 2.0), `Y_변이`(온도편차 계수가 매끄럽게 변함)를 더함. 규칙은 24·28강과 `fig-src/regkit.py`에 있음. 24강에서 추가 |
| `practice/hanbit_dong_digitized.gpkg` | 면 | `hanbit_dong.gpkg`의 꼭짓점을 ±0.5 m 안에서 흔들어 따로 그린 경계처럼 만든 것. 퀸 인접으로 이웃을 만들면 150개 동이 모두 섬이 됨. 4강에서 추가 |

## 받는 법

GitHub에서 파일을 누르고 오른쪽 위 **다운로드**(Download raw file) 버튼으로 받음. 전체를 한 번에 받으려면 책 Release의 zip을 받음.

## 다시 만들기

GeoStat 엔진 환경에서 실행함. 같은 규칙과 같은 난수 시드를 쓰므로 언제 실행해도 같은 파일이 나옴.

```
cd engine
uv run python ../book/data/make_hanbit.py
uv run python ../book/data/make_hanbit_panel.py   # 행정동 패널 (33강에서 추가)
```

구성 요소(행정동, 인구, 지표온도, 출동 등)마다 난수 흐름을 따로 씀. 나중에 새 변수를 더해도 이미 책에 쓴 값은 바뀌지 않음.
